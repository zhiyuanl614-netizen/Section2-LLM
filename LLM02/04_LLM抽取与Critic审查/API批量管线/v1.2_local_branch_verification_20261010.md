# v1.2 local-text branch implementation & verification supplement

**Date:** 2026-10-10 (local workspace session)  
**Relationship to audit:** This is an addendum to `local_api_offline_readiness_audit_20261010.md`; it records the separate implementation branch added afterward. The earlier audit remains a historical snapshot of the original scripts.

## Implemented (isolated from original pipeline)

- Safe Step 1 wrapper: `step1_run_versioned_batch_local.py` requires a fresh output directory, calls the existing slicer, records source PDF SHA-256 before/after and hashes generated outputs.
- Safe Step 2 wrapper: `step2_run_versioned_local.py` requires a completed Step 1 manifest, checks the Step 1 JSON hash and document/source-name correspondence, and writes into a fresh directory with input/script/output hashes.
- New versioned Step 3 index builder/loader: `../../03_证据索引与混合检索/step3_build_hybrid_index_v1_2_local.py` and `step3_hybrid_retrieval_v1_2_local.py`; explicit evidence/index paths, ID-order validation, local-only FastEmbed by default, and no-overwrite target checks. The original fixed-path indexer/loader are not changed.
- Local API client: `llm_api_client_v1_2_local.py` accepts only loopback or explicitly approved private numeric IPs (or no-network dry-run), permits an empty local API key, disables environment proxies and redirects, and has no remote provider/fallback.
- Step 4 orchestrator: `step4_api_batch_extraction_v1_2_local_text.py` writes to a fresh run ID, hashes inputs/index/code, supports optional fail-closed tokenizer preflight, validates model output, records call IDs, and has no truncation/fallback behavior.
- Scope safeguards: active model schema has D01/D02/D04–D10 only; formula-only fallback `Out_Of_Scope_Formula_Only` is withheld from model input. D03 is not sent to models and is written as a separate status JSON in `06_范围状态_D03/`, not in the nine-dimension result file. `B001-PDF-03:D02` is forcibly kept `adjudication_required`; no pending boundary option is treated as approved.
- Operator notes and a separate `.env.local.example` are in `README_LOCAL_v1.2_text_scope.md`. During the workspace cleanup, the only `.gitignore` was removed as requested; there is no `.git` repository here. If a repository is later initialized, add `.env.local` to its ignore rules before storing credentials.

## Not verified / go-no-go boundary

This workspace has `numpy` and `requests`, but currently lacks `rank_bm25`, `fastembed`, `transformers`, and `pymupdf`. The tests stub the index dependencies and use a local HTTP mock. Therefore:

- no real PDF was processed through Step 1/2;
- no real FastEmbed model was downloaded, loaded, or used offline;
- no original on-disk BM25 index was loaded through the new loader;
- no tokenizer-based preflight was executed;
- no real local LLM service/model was contacted, and no generation quality/latency is established;
- strict machine-level disconnection is not proven (the client prevents its own proxy/redirect/public-endpoint paths, but OS firewall and model-server telemetry remain host-level responsibilities).

**Status:** Python/logic-level mock verification passed; **not yet a real end-to-end offline run and not approved for production extraction**. Next acceptance gate is to install required dependencies and prepare local FastEmbed/tokenizer/LLM weights on the target machine, run Step 1/2 into new batch directories, build a new local-only index, then do a one-document real local-service pilot with `--require-token-preflight` and manual evidence review. Do not overwrite or merge the original B001/v1.0 records.
