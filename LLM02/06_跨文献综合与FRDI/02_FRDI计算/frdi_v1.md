## 1. 方法定义（计算前冻结，详见脚本内注释）

### 1.1 ESI（领域稀缺度）

对候选方向k，定义每篇文献在该方向构念上的"成就等级" `achievement_score ∈ {0,1,2}`（量表定义见脚本注释，依据Step 6已核验标签组合）：

```
ESI_k = 1 - mean(achievement_score across 5 docs) / 2
```

分数越接近1表示该方向在本语料中越"空白"（领域稀缺度越高）。

### 1.2 TGM（时间动量）

```
TGM_k = clip( (mean(pub_year of achievers) - mean(pub_year of all 5 docs)) / year_span , -1, 1 )
TGM_k_normalized = (TGM_k + 1) / 2   # 映射到[0,1]，0.5为中性
```

若该方向在全部5篇中 `achievement_score` 均为0（无任何"成就者"），则样本中没有可供计算动量趋势的数据点，返回中性值0.5并标记 `no_data_points=True`——**这表示"无法计算"，不表示"动量为零/停滞"**，不得混淆解读。

**出版年份已知的可靠性局限：** 本语料5篇文献的"印刷卷期年份"与"DOI字符串内嵌年份令牌"均相差1年（一致的 online-first 模式：DOI年=印刷年-1，详见 `02_PDF清洗与分块/01_Zones/step1_sliced_pdf_corpus.json` 的 `metadata_warnings` 字段）。其中 B001-PDF-05 的印刷卷期年为2027——**晚于本次计算的当前日期（2026-10-06）**，明显是期刊提前分配的未来印刷卷期号，而其DOI年份令牌2026更接近真实的论文可获得时间。遵循本项目既定规则（"保留PDF标注的卷期年，不擅自据DOI改年"），本报告以**印刷卷期年为主计算基准**，同时完整报告**DOI年份令牌作为敏感性分析基准**，不隐藏该项选择对结果的影响。

### 1.3 LCI（局限性关联置信度）

对候选方向k，Agent对每篇文献的D10局限性陈述与该方向的关联强度打0-3分（量表与逐篇评分依据见脚本注释）：

```
LCI_k = mean(limitation_relevance_score across 5 docs) / 3
```

### 1.4 FRDI 合成

```
FRDI_k = w_ESI * ESI_k + w_TGM * TGM_k_normalized + w_LCI * LCI_k
```

**主权重方案（冻结）：** 等权重 `w_ESI = w_TGM = w_LCI = 1/3`——选择等权重是为了避免被质疑"按期望结果反推权重"，不代表三个成分在理论上同等重要。
**敏感性权重方案：** `ESI_dominant (0.6/0.2/0.2)`（弱化对TGM数据质量弱点的依赖）、`TGM_excluded (0.5/0/0.5)`（完全剔除数据最弱的TGM成分）。

## 4. 稳健性分析结论（本报告最重要的结论，优先于任何单一排序）

1. **候选方向 3-1（第3章·冷却水热-水力建模空白）在全部6个测试场景中排序均为最低。** 这是本次FRDI计算中唯一稳健（对权重方案和年份基准选择不敏感）的结论：相对于另外两个方向，在本5篇语料范围内，该方向的"空白程度"证据最弱（ESI=0.9为三者中最低）且作者自陈局限性中完全没有与其直接相关的内容（LCI=0），应被排在三个候选方向中的相对次要位置——但仍需注意0.9的ESI本身已经很高，"相对最低优先级"不等于"不值得研究"。
2. **候选方向 4-1（第4章·cyber快感知空白）与 5-1（第5章·人口/社会脆弱性空白）的相对排序对计算假设高度敏感，不构成可靠结论。** 6个场景中有5个场景4-1排序更高，但在采用"主权重方案+印刷年份"这一本报告指定的主配置下，5-1反而略高（0.560 vs 0.544，差距仅0.016，远低于可被视为有意义区分的阈值）。**本报告不对这两个方向谁"更优先"做出结论性判断**，仅陈述：4-1 的证据空白最彻底、最一致（D04在5/5篇均为`Not_Addressed`，不依赖任何单篇边界判断），而5-1的证据链条虽然也未完整实现，但其"部分进展"（2/5篇达到关键设施层级）使其ESI/LCI评分略低于4-1，但其TGM因为恰好是本语料中最新的2篇文献（PDF-04、PDF-05）表现出该方向性的部分探索，所以时间动量分量更高——哪个因素应该被赋予更高权重是价值判断问题，本报告不代为决定。
3. 第3-5章写作时，若要援引本FRDI结果排序候选方向的撰写优先级，应同时呈现第4节的稳健性分析，不应只报告单一场景（尤其是主权重方案+印刷年份这一恰好把5-1排在4-1之前的场景）而掩盖其对假设的敏感性。
