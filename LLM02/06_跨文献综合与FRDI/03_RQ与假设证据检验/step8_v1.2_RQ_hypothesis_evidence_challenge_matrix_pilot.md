## 二、三项 RQ 与可证伪假设

### 3-1 — 厂内冷却水过程与水—电运行耦合

**拟议 RQ：**在耦合水—电系统研究中，热电厂厂内冷却水需求/过程被文字明确表示到什么程度，又如何与水系统供给、泵送或电力运行/控制决策相连？

**待检验假设 H3-1：**在后续符合纳入标准的文献中，通用的“向电厂供水”依赖或把冷却需求当作水网需求，可能多于对厂内冷却过程、运行约束及其与系统决策联动的明确描述。这是待检验命题，不是当前5篇已证明的领域事实。

- **样本内支持/线索：**PDF-01 的模型文字描述一般水系统组成；PDF-02 背景提到电厂冷却，但其本文模型文字聚焦配水系统运行；PDF-05 将量化冷却系统对供水能力的依赖列为未来工作。证据索引：`B001-PDF-01-ZB-S05-2-1-C001`、`B001-PDF-02-ZA-S01-I-C001`、`B001-PDF-02-ZA-ABSTRACT-C001`、`B001-PDF-05-ZD-S17-4-C003`。
- **反例/限定：**PDF-04 的文字将冷却用水纳入水系统需求，并描述供水来源与泵送，是明确反例；因此不能写成“现有研究没有冷却水建模”。证据：`B001-PDF-04-ZB-S04-II-C001`、`B001-PDF-04-ZD-S48-B-C001`。
- **边界不确定性：**PDF-03 的供水设施—电厂通用依赖确实被表示；争点是这是否足以算“厂内冷却过程建模”。其冷却专属需求、厂内状态/约束、控制对象或性能指标在已核文字中未明确。证据：`B001-PDF-03-ZB-S03-2-1-C006`、`B001-PDF-03-ZB-S21-5-2-C001`。不得把 D02 暂定标签当作专家终审。
- **会削弱 H3-1 的后续证据：**若扩展文献中多项独立研究均以自然语言明确描述冷却专属过程/状态或约束，并把它们接入水—电运行、调度或控制决策，则“此类细化仍少见”的假设应被削弱或缩窄。仅有通用供水依赖、背景提及、或未来工作建议，不等同于完整厂内过程耦合。

### 4-1 — 信息层快感知与慢物理过程的预警/主动控制

**拟议 RQ：**研究是否明确把快速信息层（如 SCADA/通信/状态感知）与较慢的水力、热或物理过程联结，并将该联结用于预警或主动/闭环控制？若有，具体联结链条是什么？

**待检验假设 H4-1：**多阶段运行、前瞻性调度或单独的信息层讨论可能存在，但“快速信息/感知 → 慢物理状态演化 → 预警或主动/闭环控制”的完整文字证据链在后续纳入文献中可能更少。该假设要求检验**链条是否被明确连接**，不能把相邻构件自动拼成完整机制。

- **样本内支持/线索：**沿用记录中 D04 在5篇均为 `Not_Addressed`；PDF-04 将 SCADA 通信中间件列为未来工作。前者只表示该先导样本的文本标签分布，且 D04–D10 在本 v1.2 综合中沿用 v1.0 记录，未重新复核。证据：`B001-PDF-04-ZD-S52-X-C002`。
- **反例/邻近证据：**PDF-01、PDF-02 有多阶段或日前运行描述，PDF-05 有前瞻/主动决策相关描述。这些提醒我们样本并非没有主动运行策略；但它们本身不证明信息层快速感知驱动了对慢物理过程的预警/闭环控制。证据：`B001-PDF-01-ZB-S06-2-2-C001`、`B001-PDF-02-ZA-ABSTRACT-C001`、`B001-PDF-05-ZC-S15-3-4-C003`。
- **会削弱 H4-1 的后续证据：**若多项独立研究明确给出上述完整链条，并说明感知更新、物理响应与控制动作之间的时间关系，则应缩窄或否定“完整机制少见”的假设。只有 SCADA 存在、只有多阶段调度、或只有预测模型，都不足以单独确证或反驳完整构念。

### 5-1 — 从网络/设施结果延伸到人口与社会脆弱性

**拟议 RQ：**基础设施中断或韧性研究把影响量化到哪一层：网络服务、关键设施、地区，还是人口暴露/社会脆弱性？影响链是否把服务损失连接到人群层面的结果？

**待检验假设 H5-1：**后续文献中，网络性能、关键设施或具名地区层面的影响分析可能比人口暴露、社会脆弱性或分布差异的量化更常见。该假设不是“没有现实影响研究”，而是关于影响终点层级的可检验命题。

- **样本内支持/线索：**沿用标签中 D07 有网络服务或关键设施层描述；D08 多数未标出人口/社会终点。须记住这些是5篇的文本观察，且 D04–D10 沿用 v1.0 记录。证据索引：`B001-PDF-03-ZB-S09-3-2-1-C001`、`B001-PDF-04-ZC-S29-C-C001`、`B001-PDF-05-ZD-S17-4-C001`、`B001-PDF-05-ZD-S11-3-C001`。
- **反例/限定：**PDF-04/PDF-05 已呈现关键设施或具名地区层级的现实影响分析；这是真实进展，但不自动等于已量化人口暴露或社会脆弱性。因此不能写成“没有实际影响分析”。
- **会削弱 H5-1 的后续证据：**若扩展文献中广泛将物理服务中断与人口暴露、脆弱性指标、分配影响或差异化恢复结果明确连接并量化，则应削弱“人群/社会终点较少”的假设。

## 三、后续 LLM 证据挑战的统一规则

1. **每项断言必须有证据 ID。**保留原文定位（PDF、物理页/章节、evidence ID）；只有需要逐字引用时才从现有 evidence block 中精确截取，不凭记忆重写引文。
2. **每条候选证据标明角色：**直接支持、部分/邻近支持、反例、边界不确定、文本未陈述或范围外。不得把背景提及等同于方法实现，也不得把未来工作等同于当前已实现模型。
3. **沉默不是否定证据。**“未发现/未陈述”只能限定在已检查的文字、章节和检索范围；对完全性不足的负面判断标成不确定，不能断言论文或领域绝对没有。
4. **反例需对应同一构念层级。**例如关键设施/地区分析是 5-1 的中间层反例，不应误写成社会脆弱性量化；多阶段调度也不是 4-1 完整感知—物理—控制链的自动反例。
5. **审核独立性如实披露。**同一会话 Agent 的生成、批评和复核不能称作独立双模型或独立人类专家审核；最终代码本边界与关键结论需由真实领域研究者抽查。
6. **公式范围维持不变。**任何必须查看、转录、推导或分类公式才成立的主张，在当前版本均不评估；原 PDF、evidence blocks 和公式风险元数据仍保留。
